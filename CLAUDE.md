# Virtuoso System (Virtuous Accounting Solutions CC)

Single-file demo app: `index.html` (vanilla JS, no build step). PWA files: `manifest.webmanifest`, `sw.js`, icons. Hosted with GitHub Pages from `main` (push to deploy): https://mrandrecloete-hub.github.io/virtuous-system/

## Facts
- Namibia, NAD, financial year March to February (FY2027 = Mar 2026 to Feb 2027).
- Demo data only, held in one `state` object; resets on reload. No backend yet.
- Demo logins: admin@firm.example / Admin#2026, selma@firm.example / Welcome#1, tobias@firm.example / Welcome#4 (must change password).
- Payroll is non-tax. Do not invent Namibian PAYE/SSC rates; they need verified, effective-dated rules.
- Brand: navy and gold theme, logo files `logo.png` (white background), `logo-dark.png` (transparent, for dark backgrounds). App name "Virtuoso System"; company name stays "Virtuous Accounting Solutions CC".

## Code layout (inside index.html)
- State and data near the top of the script; `VIEWS` map picks the page; `render()` rewrites `#view`; delegated click/submit/change/input handlers.
- Modules: dashboard, employees, timesheets, clients and billing, leave, loans, payroll and payslips, wet signature, petty cash (receipts, sheets, reconcile), stationery, cash taken, KYC forms builder, staff requests, reports, audit log, alerts.
- Excel upload uses SheetJS from cdnjs.

## Backend (in progress)
- `supabase/migrations/` 0001-0014: schema, RLS, audit, payroll lock, storage, assistant usage cap. Tested locally on Postgres with stubbed auth only.
- Assistant: `assistant.js` (panel) + `assistant-engine.js` (built-in keyword brain, no AI service or key; reads live data through RLS, or sample data in `?demo`). `supabase/functions/assistant/` is an optional AI version (needs `ANTHROPIC_API_KEY` as a Supabase secret) and is currently not used by the panel.
- `auth.js`: live Supabase sign-in (replaces demo login when `config.js` is filled; `?demo` forces the sample-data demo). Tested only against a fake Supabase in a browser. `live-employees.js` + `supabase/functions/admin-users/`: live Employees screen (invite, reset password, disable) via an admin-only Edge Function; the service-role key is used only there, as an auto-injected secret. `live-time.js`: live Clients & billing, Timesheet and Approvals (timesheets only; billing counts approved hours; no timer or wet-signature in live mode yet). Tested against an in-memory fake DB only. `live-petty.js` + migration 0009: live Petty cash page (cash taken, server-side `settle_advance`) and month folders (LFT (Losper Family Trust) and Virtuoso, each with Bank and Cash) for scanned documents in the private `documents` bucket under `petty/<YYYY-MM>/<entity>/<kind>/`; works in `?demo` too (in memory). Menu labels: Petty cash (was Cash taken), Petty cash sheet (was Cash sheets). Clients page has a Time spent on tasks breakdown. `assistant-forms.js`: rule-based form builder in the assistant (create from a prompt, edit in plain language incl. show/hide rules, templates, quiz from pasted text, email drafts, response summary). Writes into `state.forms` (same list as Client KYC); forms are NOT saved to the database yet. Not possible without an AI model/outside services: chat/phone agents, WhatsApp etc., app builder, PDF reading. Migration 0010 is an idempotent repair for the `documents` bucket policies. `live-leave.js` + migration 0011: live Leave and Loans (staff) with server-side rules (balance, overlaps, sick-note rule, one active loan, atomic `decide_leave`/`decide_loan`, `withdraw_request`, `set_leave_balance`); approvals for leave/loans are in `live-time.js` (Approvals page); admin sets balances on the live Employees page. Default balances are PLACEHOLDERS (15/10/3). Loan instalments are not yet deducted in payroll (payroll not connected). `live-payroll.js` + migration 0012: live Payroll (admin: month picker, draft from pay details, overtime/other-deduction inputs, finalise locks + advances loans, payment list without bank details) and Payslips (staff, finalised only). NON-TAX: no PAYE/SSC. Overtime = hours x (basic / monthly hours) x multiplier, both editable firm settings (173.33 and 1.5 are the demo's values, not statutory). Pay details panel is on the live Employees page (`set_pay_profile`). Not done: bank account storage/bank file, payslip email, wet signature, reimbursements. `form-builder.js`: admin page FORM BUILDER (People > Form builder): forms list + create (describe / templates / quiz / blank), then an editor with BUILD (element palette with drag-and-drop or click, live canvas, Form Designer: colours, styles, themes, layout, field properties incl. show-if, plain-language command bar, preview), SETTINGS (form settings, emails, conditions, thank-you, integrations, approval flows) and PUBLISH (quick share link, embed code, assign/notify, email invite, prefill links, printable PDF, platforms). Uses `window.VIRTUOSO_FORMS` from `assistant-forms.js`. `live-forms.js` + migration 0013 save forms/submissions to the database (admins write; quiz answer keys in private `settings`); `form.html` + `public-form.js` is the public page for shared client forms (`form.html?id=<uuid>`, `&embed=1`, `&p_<label>=value`); anonymous visitors can read only public columns and insert Pending submissions (hourly cap). sw.js only caches same-origin files. Form builder also has Preview and Fill now (opens the in-app fill screen with the form's design; responses save to the database, files go to private storage) and Export/Import of a form as a `.form.json` file (import is validated and sanitised: whitelisted field types, remapped ids, never trusted). Staff add notes on their own Timesheet page. Other modules still run on demo `state` behind a yellow banner; wiring modules to Supabase is not done. `bear.js` (Bruno the bear, original inline-SVG mascot, `VIRTUOSO_BEAR.svg`) + `assistant.js` (Bruno chat panel: hero, `+` tools menu, Voice via the browser's SpeechRecognition, suggestions) + `ai-tools.js` (AI Tools page with breadcrumb dropdown: AI Form Builder (admin), Data Assistant, Business/Cold email, Apology, Payment reminder, Contract template, Article summarizer (extractive), Name generator, Chart maker with SVG/PNG download; `VIRTUOSO_TOOLS`).
